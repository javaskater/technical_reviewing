## plotting two dimensional functions
```python
>>> xs = torch.linspace(-5, 5, 3);
>>> xs
tensor([-5.,  0.,  5.])
>>> x1, x2 = torch.meshgrid(xs, xs, indexing="ij")
>>> x1
tensor([[-5., -5., -5.],
        [ 0.,  0.,  0.],
        [ 5.,  5.,  5.]])
>>> x1.flatten()
tensor([-5., -5., -5.,  0.,  0.,  0.,  5.,  5.,  5.])
>>> x2
tensor([[-5.,  0.,  5.],
        [-5.,  0.,  5.],
        [-5.,  0.,  5.]])
>>> x2.flatten()
tensor([-5.,  0.,  5., -5.,  0.,  5., -5.,  0.,  5.])
>>> xs2 = torch.vstack((x1.flatten(), x2.flatten())).transpose(-1, -2)
>>> xs2
tensor([[-5., -5.],
        [-5.,  0.],
        [-5.,  5.],
        [ 0., -5.],
        [ 0.,  0.],
        [ 0.,  5.],
        [ 5., -5.],
        [ 5.,  0.],
        [ 5.,  5.]])
>>> ys = xs2[:,0] ** 3
>>> ys
tensor([-125., -125., -125.,    0.,    0.,    0.,  125.,  125.,  125.])
>>> ys2 = ys.reshape(3,3)
>>> ys2
tensor([[-125., -125., -125.],
        [   0.,    0.,    0.],
        [ 125.,  125.,  125.]])
>>> ys2.T # we need to transpose because we start from the lower y to the upper y and for each line from lower x to upper x 
tensor([[-125.,    0.,  125.],
        [-125.,    0.,  125.],
        [-125.,    0.,  125.]])
```
