## The GET Request has two parameters

- page and sort
  - [page works](https://www.baeldung.com/rest-api-pagination-in-spring)
  - [sort does not work](https://docs.spring.io/spring-data/rest/reference/paging-and-sorting.html#paging-and-sorting.sorting)
- The Paging works because the **superheroes/src/main/java/com/example/springbootsuperheroes/superheroes/antiHero/controller/AntiHeroController.java**
  - has been adapted

```java
int toSkip = pageable.getPageSize() * pageable.getPageNumber(); // The Offset

// Mapstruct is another dto mapper, but it's not straight forward
var antiHeroList = StreamSupport
        .stream(service.findAllAntiHeroes().spliterator(), false)
        .skip(toSkip).limit(pageable.getPageSize())
        .collect(Collectors.toList()); // Adding .skip and .limit
```
