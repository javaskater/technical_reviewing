```bash
(PACKTRL) jpmena@jpmena-HP-OmniBook-X-Flip-Laptop-14-fm0xxx:~/CONSULTANT$ deactivate # leaving the venv
jpmena@jpmena-HP-OmniBook-X-Flip-Laptop-14-fm0xxx:~/CONSULTANT$
```
